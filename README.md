# Attribution playground (anonymous demo)

Static snapshot of the token-attribution viewer (Qwen3-VL-8B) for the paper's methods and
baselines. Everything shown is pre-computed from the evaluation outputs: per-sample
RISE/MAS records, mean insertion/deletion curves, per-token attribution scores, and
dataset samples (question, options, gold answer, model output, image).

No author, institution or environment information is contained in this repository.
